# 账号域健康日报

## 一、何时调用
- 每日晨报例行；账号域异常升级评估时；周会经营回顾。

## 二、执行步骤
1. **四格汇总**：增长（新账号/新租户）、活跃（登录成功去重）、安全（失败/锁定/强制下线）、审计（僵尸/超权/失联 owner 计数）；
2. **基线比对**：各格 vs 7 日基线，超 3σ 标红并附判读；
3. **升级分流**：P1（批量事故/break-glass 超期）→ 真人审批卡；P2/P3 → 台账自裁；
4. **晨报输出**：一段人话结论 + 四格数字 + 待办清单，进入仙女座晨报管线。

## 三、边界与围栏
- 日报只读：不处置，处置走各专员技能；
- 数字必须可下钻：每一格都能展开到具体台账记录。

## 四、协作
- 上游：五看板投影（platform-ops/accounts/dashboards）；下游：晨报编排、真人审批卡。
