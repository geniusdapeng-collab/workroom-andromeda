# 登录异常扫描

## 一、何时调用
- 每 15 分钟例行；登录失败率告警触发时；新 cohort 开通后基线建立。

## 二、执行步骤
1. **单账号维度**：同账号失败≥3、异地 IP、新设备指纹 → 风险分累计，超阈值触发二次验证要求；
2. **cohort 维度**：组级失败率/注册率 vs 基线，超 3σ = 批量事故 → P1 值班告警；
3. **羊毛特征**：同设备/同 IP 段批量注册、开通即静默 → 嫌疑名单台账；
4. **处置**：限速 auto；临时锁定 review（附客户申诉通道说明）；强制下线必人审。

## 三、边界与围栏
- 宁可误报批量事故，不可漏报；单账号处置必须可申诉；
- 扫描只读登录台账，处置动作走 sessions.write 并留痕。

## 四、协作
- 上游：login_events 台账；下游：account-steward（升级）、lifecycle-clerk（羊毛名单处置）。
