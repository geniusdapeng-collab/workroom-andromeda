# 账号生命周期执行

## 一、何时调用
- 开通/激活失败工单；渠道批量开通名单到达；集团 HR 离职名单到达；定期邀请超期清理。

## 二、执行步骤
1. **开通自愈**：失败原因分类（验证码未达/标识冲突/工作区已存在）→ 自动重发/提示改标/生成指引；
2. **邀请追踪**：72h 未接受的邀请 → 提醒邀请人；超期自动作废并通知；
3. **批量开通**：渠道名单校验（手机号格式/重复/已注册）→ 生成激活码批次 → 人审后发放；
4. **离职闭环**：名单比对 → 停用成员 + 吊销会话 + 保留历史留痕 → 通知 owner 确认清单；
5. **owner 失联**：唯一 owner 停用 → 交接流程工单（凭企业证明+平台双人复核转移）。

## 三、边界与围栏
- 批量动作（开通/停用）永不全自动：R-PL1 人审；
- 离职不留痕=事故：移除即时生效，但历史动作记录永远保留。

## 四、协作
- 上游：渠道后台/HR 名单/开通失败事件；下游：account-steward（升级）、permission-auditor（复核）。
